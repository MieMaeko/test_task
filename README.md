# Прототип блока Progress
Компонент отображает прогресс выполнения в виде круговой дуги.

## Запуск

### Локально
Откройте файл `progress.html` в браузере.

### GitHub Pages
Главной страницей является `/progress.html`.

## Состояния

### Normal
Базовое состояние. Путём задания **Value** можно управлять 
размером дуги:
- начало дуги соответствует **12 часам**
- конец при увеличении Value дуга растёт **по часовой стрелке**
- достигает начала при значении **100**

### Animated
Независимое состояние, при котором элемент дуга начинает вращаться с некоторым периодом по часовой стрелке.

### Hidden
Скрывает круговой индикатор со страницы, элементы управления остаются доступны.

## Управление в демо

- **Value** — текстовый ввод числа 0…100
- **Animate** — переключатель on/off (включает/выключает вращение)
- **Hide** — переключатель on/off (скрывает/показывает индикатор)

## API

Компонент предоставляет API-функцию `progressApi(rootElement)`, которая возвращает объект с методами управления состояниями.

### Методы

- `setProgress(value)` — установить значение прогресса (0..100)
- `setHidden()` — переключить состояние Hidden (toggle)
- `setAnimated()` — переключить состояние Animated (toggle)

### Пример использования

```js
const root = document.querySelector('.progress-block');
const api = progressApi(root);

api.setProgress(75);   // установить значение
api.setAnimated();     // переключить вращение
api.setHidden();       // переключить скрытие
